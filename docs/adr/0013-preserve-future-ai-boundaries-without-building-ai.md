# 保留未来 AI 边界但不在第一版构建 AI

第一版不包含任何 AI 依赖、界面、数据任务或空 Module。工作区、稳定资料身份、主要阅读材料、可恢复锚点和 Markdown Reading Material 是未来 AI 能力可以依赖的既有领域，而不是为 AI 特制的临时结构。

未来 Agent Runtime 必须通过可替换 Interface 隔离；书籍 Agent 从模板复制后独立存在且没有隐藏长期记忆；趣味技能主动触发并只使用白名单工具。

未来书籍知识采用书籍索引、章节知识笔记和原文章节片段三层渐进披露，初始不依赖向量 RAG。AI 笔记使用 Markdown，并直接复用当前材料与编辑能力。

未来同步后端只中转端到端加密副本，不拥有阅读领域规则，不同步原始书籍、API Key、伴读对话或运行时状态。四端加密验证失败时延期同步，不得降级为服务端明文。
