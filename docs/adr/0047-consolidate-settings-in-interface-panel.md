# 设置统一收敛到界面活动面板

工作台主题、背景光和阅读排版统一由活动栏的“界面”活动面板承载；工作台主题仍是本机应用偏好，阅读排版继续区分书籍级覆盖与全局默认，PDF 页面适配/缩放继续属于当前 ReadingView 的视图状态。旧的阅读排版按钮和菜单项只执行 `reader.typography.open` 聚焦该面板，不创建独立对话框或第二套设置状态；界面面板默认关闭，没有活动材料时默认进入全局设置并禁用书籍设置。宽/中布局以内联面板呈现，紧凑布局以覆盖抽屉呈现，Escape 和 Android 返回键关闭后焦点归还活动栏。这样避免并存的排版对话框与主题入口，同时保留既有排版能力和材料级语义。
