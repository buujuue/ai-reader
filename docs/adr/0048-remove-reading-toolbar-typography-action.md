# 阅读工具栏左上角仅保留排版占位

阅读材料工具栏左上角原先用于打开“界面”活动面板的阅读排版按钮不再承载交互；该位置保留同尺寸静态占位，以维持源码模式入口和工具栏布局的稳定性。阅读排版仍由“界面”活动面板提供，应用顶栏的“视图 → 阅读排版”继续通过 `reader.typography.open` 聚焦面板。

这样可以避免阅读正文附近出现重复的面板跳转入口，同时保留现有排版能力、键盘可达的顶栏入口和跨布局的工具栏结构。占位不注册 Command、不参与 Tab 顺序，也不改变 Workspace State、Reader Runtime 或排版数据模型。
