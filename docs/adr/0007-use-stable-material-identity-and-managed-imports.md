# 使用稳定资料身份、完整指纹与托管导入

每份 Reading Material 使用稳定 UUID `BookId`。完整内容指纹用于精确查重与完整性校验，但不是稳定身份。标题、作者和标识符等元数据不得触发自动合并。

所有导入文件复制到应用托管书库。导入采用 `stage → inspect → commit`：Rust 流式复制并计算指纹，TS 通过 BookDocument 检查格式和提取信息，Rust 再查重并以 pending/ready 状态完成文件与数据库提交。启动时恢复或回滚中断提交。

首个导入切片（“托管导入一份 EPUB”）以更轻的等价机制落地崩溃安全：启动时清空暂存目录并移除无数据库记录的孤儿托管文件，保证不残留半本书或半条记录；显式的 pending/ready 状态机与更完备的恢复协议在“严格查重并恢复中断导入”切片落地。

相同指纹在活跃书库中返回既有材料，在回收站中恢复原材料；不同指纹始终创建新材料。旧决定“沿用 Readest 抽样 MD5 与 metaHash”在本项目中失效。

删除先进入应用内回收站并保留全部数据；永久删除才级联移除托管文件和记录。来源元数据不可编辑，用户整理通过覆盖层实现。
