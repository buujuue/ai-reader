# 可重排 EPUB 跟随全局工作台主题

## 决策

可重排 EPUB 的正文主题由 `WorkbenchAppearance` 的五个本机主题统一驱动：科技黑使用不透明的 `#1e2023` 正文纸张与 `#ffffff` 普通正文，其余四主题使用各自工作台正文纸张令牌与 `#000000` 普通正文。主题切换通过现有外观 Command 回调到 `BookDocument`，只更新已经存在的可重排 EPUB Runtime；新建、挂起回切和冷重建在打开前读取当前本机主题。

阅读排版中的旧 `ReadingTheme` 仍保留给尚未迁移的格式和历史 Workspace State，但不再影响可重排 EPUB 的实际配色。EPUB 的字体、字号、行距、页边距和分页/滚动仍由原有全局默认与材料级覆盖管理；旧主题字段不作为 EPUB 的颜色来源，也不新增材料级颜色覆盖。

## 样式保真与边界

正文注入使用固定主题令牌和可逆 CSS 变量：默认继承正文色以及样式表、内联样式和旧式 `color` 属性中的精确纯黑声明跟随主题；显式彩色、灰色、相近黑色色码、局部背景、背景图片、图片、SVG、公式、高亮、搜索结果和选区保持原样。主题转换只处理 XHTML/CSS 的正文颜色声明，不改写托管材料字节、搜索/CFI 规范缓存或批注锚点。书内存在 body 背景时，分页器的主题变量置空以保留该背景；透明正文才使用主题纸张色。

固定版式 EPUB、整页图片 EPUB 和 PDF 不接入该全局正文配色。主题仍保存于既有本机外观偏好，不进入 Workspace State、阅读材料或完整书库备份；背景光保持独立状态。

## 参考实现与取舍

Readest `apps/readest-app/src/utils/style.ts` 的 `getColorStyles`、纯黑兼容选择器和 `FoliateViewer` 的章节刷新行为作为实现参考。AI Reader 只采用“渲染器样式注入 + 新章节复用 + 纯黑精确匹配”的必要行为，独立实现固定令牌和 CSS 变量，不引入 Readest 的链接重着色、浅色局部背景修复、图片滤镜或 PDF 全局主题。

该决策替代旧的“工作台外观不改变正文排版”约定，但仅在可重排 EPUB 范围内替代；ADR-0045 的本机偏好所有权与 ADR-0047 的界面面板归属继续有效。
