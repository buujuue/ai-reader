# 01 — 让可重排 EPUB 正文跟随五个全局主题

状态：已按用户确认发布为 [GitHub #71](https://github.com/buujuue/ai-reader/issues/71)，标签 `ready-for-agent`。原生依赖：受 #70 阻塞；只有阻塞事项完成后才能进入执行前沿。

## 要交付的行为

用户在“界面”活动面板选择科技黑、简洁白、护眼橙、清新绿或甜蜜粉时，可重排 EPUB 的页面基础背景立即使用同一全局主题的不透明正文纸张色；普通正文在科技黑下显示为纯白，其余四主题显示为纯黑。既有彩色文字、局部背景与图形内容保留原貌，主题切换不移动阅读位置，也不改写书籍内容。

这是现有工作台外观能力的后续扩展：复用唯一五主题入口、本机偏好和 Command/BookDocument 管线，随本切片提供其它流式格式可复用的配色能力。只在实现这条完整路径时做必要的窄范围整理，不单独建立横向重构工单。

## 验收标准

- [ ] 五个主题与工作台使用同一有效主题来源及同一组正文纸张令牌；科技黑普通文字为 #ffffff，其余四主题为 #000000，正文背景稳定不透明，不叠加工作台光晕、渐变或玻璃效果。
- [ ] 继承 Readest 默认正文配色与纯黑声明兼容方式：普通默认文字以及明确纯黑的样式表、内联样式、旧式颜色属性跟随主题；不扩大为所有灰色文字强制改色。显式彩色文字及其继承后代、显式灰色、透明文字保持原色。兼容操作精确识别颜色声明，不误匹配背景属性或与黑色色码共享前缀的彩色色值。
- [ ] 页面基础背景随主题更新；书内局部背景色、背景图片、彩色标题/链接/脚注/代码/表格文字、图片、SVG、公式保持原貌。批注高亮、搜索结果和选区的既有颜色及交互语义保留；不增加单本颜色覆盖开关或图片滤镜。
- [ ] 当前 EPUB 设置只使用已有五主题入口，生效摘要显示实际全局主题；旧浅色/护眼/深色不再作为适用 EPUB 的主题选择。其它格式仍在后续切片或原有边界内，不为尚未接入的格式显示已生效的错误说明。
- [ ] 全局默认或材料级旧 theme 值不再覆盖适用 EPUB 的实际配色；调整或重置字体、字号、行距、页边距、分页/滚动等设置不会让主题退回旧值，也不丢失其它排版覆盖。
- [ ] 分页和滚动模式下，当前页、下一页、跨章节、双 Editor Group（同材料及不同材料）均采用最新主题；切换途中完成打开或加载章节的迟到任务不能重新应用旧主题。
- [ ] 当前可见视图立即更新；挂起标签在再次展示前更新，关闭重开和缓存淘汰后的冷重建也采用当前主题。切换主题不批量唤醒挂起对象、不突破三个 resident／两个 active 的既有边界、不用关闭重开整本书实现普通换色。
- [ ] 只修改渲染配色，阅读位置、导航历史、文字布局几何、选区锚点和批注定位不变；托管材料字节及完整内容指纹不变。反复切换主题可恢复此前主题表现，不累积有损样式替换。
- [ ] 重启及完整书库备份恢复后，正文采用当前本机主题；主题不写入书籍或整库备份。非法/缺失本机偏好继续沿用现有默认回退，背景光的独立状态保留。
- [ ] 固定版式／整页图片 EPUB 和 PDF 不应用本次全局正文配色，图像、页面尺寸及原有阅读行为保持一致；不新增 PDF 全局主题开关。
- [ ] 直接复用 Readest 合适的样式注入、章节刷新及纯黑兼容实现，记录来源与许可；保真规则优先于上游浅色局部背景修复、链接着色和图片滤镜。材料脚本、远程资源、文件权限与批注安全边界保持有效。
- [ ] 实施前记录新的主题关系 ADR，明确替代旧正文隔离约定的格式范围；同步领域术语、基础规格、视觉规范与架构说明，保留 ADR-0045 本机偏好和 ADR-0047 面板归属，其它受影响的代理说明与 CODEMAP 随代码同步。历史工单作为旧基线，不关闭或改写其正文来替代本切片交付。
- [ ] 用真实 EPUB 检查五主题下的实际文档样式，覆盖普通黑字、显式灰色、彩色后代、相近黑色的彩色色码、局部底色、背景图片、SVG/公式和批注；颜色转换可逆，保留原书颜色产生的对比限制不以未经授权的改色隐藏。
- [ ] 应用级回归覆盖主题选择、排版旧值、跨章、双组、挂起恢复、重启/备份恢复和排除格式；通过相关测试、类型检查与生产构建，并留存 Windows Tauri 主题切换与重启恢复冒烟证据。浏览器设备模拟不计作原生证据。
