## 已明确的目标

- 用户要求主题配色能够改变 EPUB 阅读材料的文字与背景：科技黑下文字为白色，其余主题下文字为黑色，背景随主题改变。
- `ebup` 按 EPUB 理解。当前代码里的五套主题名称为科技黑、简洁白、护眼橙、清新绿、甜蜜粉；若干正式文档仍保留旧名称。
- 用户指定 `grill-with-docs`，其要求结合 `grilling` 与 `domain-modeling` 进行逐项访谈并记录文档；本轮是设计访谈。

## 已核实的现状

- `CONTEXT.md` 的工作台主题与阅读主题定义明确相互独立；基础规格、架构总览、`style.md` 和 ADR-0047 同样保留工作台外观与阅读排版各自的所有权。ADR-0021 已被 ADR-0047 替代，不能把它描述成当前有效决策。
- `apps/reader/src/app/workbenchAppearance.ts:9` 定义五套工作台主题；`workbenchAppearance.css` 提供对应正文纸张令牌，但工作台切换命令当前仅保存本机外观并更新根属性，不向阅读文档应用配色。
- `apps/reader/src/domain/reader/typography.ts:15` 的阅读主题只有 light/sepia/dark，前景分别为深灰、棕黑和浅灰；不等于用户可能要求的纯黑/纯白。`resolveTypography` 目前以材料覆盖优先于全局默认。
- `typography.ts:148` 的配色注入主要设置 html/body；书内子元素显式颜色不保证被覆盖。仅联动外壳颜色不足以保证文字可读。
- `foliateViewHost.ts:374` 使用可重排渲染器的 `setStyles` 注入；固定版式保留书籍自带样式，不能直接承诺所有 EPUB 页面均可按同一路径改色。
- PDF 与 Markdown 也使用阅读排版能力。共享调色板的改动可能扩散到其它格式，需显式确定范围。
- 工作台外观按 ADR-0045 保存在本机，不进入完整书库备份；阅读排版有全局默认和材料覆盖，属于另一条设置路径。

## 决策记录

- 已明确：EPUB 需要主题配色能力；科技黑白字，其余主题黑字；背景随主题改变。
- 已确认：D1——切换五套主题时，所有 EPUB 统一跟随，不保留单本书独立配色；字号、行距、页边距等其它排版设置仍可按材料设置。
- 已确认：Markdown 也跟随主题，使用同一套正文前景色与背景色规则。
- 已确认：固定版式／整页图片 EPUB 和 PDF 暂不跟随主题；当前范围是可重排 EPUB 与 Markdown。
- 已确认：正文文字严格使用 `#000000`／`#ffffff`；背景使用每套主题的不透明正文纸张色，不使用工作台环境渐变。
- 已确认：书籍原有内容保持不变；只有普通文字允许按主题变为黑色或白色，彩色文字保持原色。
- 已确认：图片、SVG、公式、用户高亮、搜索结果和选区保留各自颜色，不参与黑白正文覆盖。
- 已澄清：用户所说的“主题配色”是界面中的五个工作台主题（科技黑、简洁白、护眼橙、清新绿、甜蜜粉）；代码中的三项旧阅读主题（浅色、护眼、深色）不是这五个主题。
- 已确认：EPUB 和 Markdown 的设置只显示五个工作台主题；旧的“浅色／护眼／深色”阅读主题选项不再显示。
- 已澄清：EPUB 与 Markdown 不新增专属主题，而是接入五个全局工作台主题的同一条配色管线；两种格式的正文基础背景适配全局主题。科技黑下普通文字为白色，其余主题普通文字为黑色，彩色文字保持原色。
- 已确认：书内显式局部背景色和背景图片保持原样，只改变 EPUB／Markdown 的页面基础背景。
- 已确认：切换全局主题时，已打开的 EPUB／Markdown 立即更新；双编辑器组、其它标签和挂起后回切均采用新主题，同时保持阅读位置、排版几何和批注锚点不变。
- 已确认：全局主题继续作为本机应用偏好保存，重启后自动恢复，不写入阅读材料或完整书库备份。
